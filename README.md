
# CodeQuest AI

CodeQuest AI is a mobile-first redesign concept for a 60-day student coding challenge. It turns daily coding practice into a clear, motivating journey using missions, streaks, XP, badges, and learning-first guidance.

## What it includes

- A landing page that explains the 60-day journey.
- A student dashboard with streaks, XP, progress, missions, and badges.
- A complete Day 12 challenge screen with proof-of-work submission.
- A local AI Coding Companion that explains, guides, and hints without giving a complete answer.
- Edge-case previews for a first-day student and a student returning after a missed day.

## Tech stack

- React + Vite
- Tailwind CSS
- React Router
- Lucide React
- Framer Motion

## Run locally

```powershell
npm.cmd install
npm.cmd run dev
```

Open the local link printed in the terminal, usually `http://localhost:5173`.
