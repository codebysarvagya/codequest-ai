# 🚀 CodeQuest AI

> **Turn coding practice into a 60-day quest.**

CodeQuest AI is a gamified coding-learning platform designed to transform traditional, passive learning into an interactive 60-day coding journey.

The platform combines daily coding challenges, progress tracking, XP, streaks, achievements, proof-of-work submission, and a real AI-powered coding mentor to keep students motivated and help them learn by solving problems.

---

# 🏆 Hackathon Problem Statement

## Problem Statement 1 — Redesign ABTalks

Traditional learning platforms often provide content but lack continuous motivation, accountability, and personalized guidance.

CodeQuest AI redesigns this experience as a **gamified 60-day coding quest**, where students can:

- Complete daily coding missions
- Track their progress
- Maintain learning streaks
- Earn XP and achievements
- Submit proof of their work
- Get personalized guidance from an AI coding mentor
- Visualize their complete learning journey

The goal is to make coding practice feel more like a **quest than a course**.

---

# ✨ Key Features

## 🎯 1. Interactive Student Dashboard

The dashboard gives students a quick overview of their current learning state.

It includes:

- Current streak
- Quest progress
- Student standing
- Today's mission
- Current XP
- Level progress
- Recent achievements
- Quest roadmap

---

## 🗓️ 2. 60-Day Quest Roadmap

Students can visualize their complete coding journey through a 60-day roadmap.

The roadmap represents:

- ✅ Completed missions
- 🔥 Current mission
- 🔒 Upcoming missions
- 📈 Overall journey progress

This gives students a clear sense of progression and encourages them to continue their streak.

---

## ⚡ 3. Daily Coding Missions

Each day contains a focused coding challenge.

Every mission provides:

- Mission title
- Description
- Duration
- Required skills
- Expected outcome
- Step-by-step guidance
- Proof-of-work submission

Students can directly start the current mission from the dashboard.

---

# 🤖 4. Real AI Coding Companion

CodeQuest AI includes a real AI-powered coding mentor using the **Google Gemini API**.

The AI Companion is designed as a **Socratic Coding Mentor**.

Instead of immediately giving students complete solutions, it provides:

- Concepts
- Hints
- Step-by-step guidance
- Roadmaps
- Debugging direction
- Personalized explanations

Students can also ask custom questions through the AI Companion.

### Example

```text
Student:
What is state in React?

AI Companion:
Provides a simple explanation and guides the student
towards understanding the concept instead of immediately
giving a complete copy-paste solution.
